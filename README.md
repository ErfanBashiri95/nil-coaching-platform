# NIL Coaching Academy Platform

A custom React + Babel frontend for NIL Coaching Academy, designed as an educational platform with course dashboards, student panels, communication tools, finance tracking, session overview, logbooks, resources, notifications, and an interactive 3D planet-based navigation system.

## Features

- React frontend without build dependency
- Custom Babel-based browser rendering
- Student and staff dashboards
- Course detail and resources system
- Finance and payment tracking
- Session overview and score management
- Score objection workflow
- Logbook management
- Internal communication and support system
- Notification system
- Profile and avatar management
- Interactive 3D planet navigation with Three.js
- Responsive mobile layout

## Tech Stack

- React
- Babel
- JavaScript
- CSS
- Three.js
- PHP API integration
- MySQL backend integration
- cPanel deployment

## Project Status

This repository contains the frontend source code only. Backend APIs, database credentials, uploads, and server configuration are excluded for security reasons.
